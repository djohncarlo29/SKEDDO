---
name: Category archive choices
description: Product rule for archiving user categories that contain sections or events.
---

Contentful user categories require an explicit choice: archive the category with its sections and events intact, or archive only the category, move events to Uncategorized, and remove its section layout. Empty categories archive directly.

**Why:** The user wants archiving to support both reversible preservation and intentional removal of the category's organization without silently changing event placement.

**How to apply:** Keep the choice subtitle concise and parallel to the Delete Group sheet. Built-in smart categories do not need this prompt because they do not own category sections or event assignments.
