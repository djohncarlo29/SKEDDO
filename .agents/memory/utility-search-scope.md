---
name: Utility search scope
description: Search priority for Archived Items and Recently Deleted.
---

Search the contents of the currently open utility first, including its events, user categories, and built-in Smart Categories. Show matching active events under “ALSO FOUND” only when the utility itself has no matches; do not mix active results into a nonempty utility result set.

**Why:** The user expects utility search to find archived or deleted items rather than surfacing active events as if they were utility contents.

**How to apply:** Preserve this priority in both inline and full-screen search modes whenever utility search or its result rendering changes.
