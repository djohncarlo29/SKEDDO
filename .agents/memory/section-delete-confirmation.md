---
name: Section delete confirmation
description: Product rule for removing event sections without deleting their events.
---

Deleting a section requires two confirmation sheets: an initial explanation and a
second “Are you sure” confirmation. The section is removed, but its events stay
in the category and become unsectioned.

**Why:** Section removal changes organization only, while the destructive wording
can otherwise make users think the events will be deleted too.

**How to apply:** Use the shared two-step section confirmation for both the
calendar/detail-view section action and the Edit Sections management sheet.
