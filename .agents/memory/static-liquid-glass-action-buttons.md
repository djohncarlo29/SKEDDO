---
name: Static Liquid Glass controls
description: Rendering boundary for fixed-color action circles and simple non-interactive cards.
---

Fixed-color action circles and simple non-interactive cards share the historical app-owned LiquidGlassView + LiquidGlassLens composition. Actions retain bloom and tap timing; surfaces omit touch, gestures, and bloom.

**Why:** The action-circle reference depends on app-specific capture, squircle, rim, shadow, and clipping values that package defaults do not reproduce. A frosted fallback or package-default button is visibly different and is not an acceptable substitute when the original appearance is required.

**How to apply:** Start from the historical action-button block in git when changing these optics; remove only explicitly requested effects and preserve its capture/view, squircle, optical border, shadow, hairline, and clip structure. Build the shared static lens style directly rather than copying `LiquidGlassButton.defaultStyle`, so action shadows cannot leak into surfaces. Static surfaces hard-code no optical rim and always resolve the app-wide `kCardShadow` internally; they expose neither override. On native platforms, static surfaces use the local capture renderer so a scaled Cupertino sheet cannot drift a screen-space filter; web keeps automatic backend selection. Action buttons retain their separate historical rim, and the search cancel xmark alone can omit the action shadow. Non-interactive surfaces using `LiquidGlassView` need intrinsic-height sizing when their parent gives loose height constraints. When a static lens needs a small overhang, use a non-layout paint transform and let the outer shape clip provide the final silhouette; layout wrappers such as `LayoutBuilder`/`OverflowBox` can collapse PlatformView-backed Notes content during intrinsic measurement. If the transform wraps the whole native view, apply the exact inverse paint transform to its child subtree so only the lens overhangs; otherwise text, fades, icons, and placeholders scale too. Keep any optical rim or hairline on the untransformed surface painter so it stays on the exact shape boundary. Render static surface shadows through `ShapeDecoration`/`BoxShadow`, not `Canvas.drawShadow`, when matching search bars or buttons; equal shadow values can still produce different spread and weight across those renderers. On Impeller, lenses under a sheet transition must derive shader origin and dimensions from the full global render transform; local dimensions remain unscaled while the route is temporarily scaled. Keep the full dynamic glass pipeline for the Floating Tab Bar, LiquidGlassSwitch, LiquidGlassSlider, and other controls whose appearance depends on live optical rendering.
