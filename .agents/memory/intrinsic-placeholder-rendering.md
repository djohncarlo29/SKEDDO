---
name: Intrinsic placeholder rendering
description: Shared behavior for one-line placeholders that overflow or rubberband at text-field edges.
---

One-line placeholders are rendered at their intrinsic width inside the field viewport. They must use clipping rather than ellipsis, show the matching edge fade when clipped, and translate with the field's horizontal rubberband offset. In AppSearchBar, keep the placeholder inside NativeTextInput's child subtree and transform it together with the field; use HorizontalEdgeFade only to measure placeholder overflow. On web, NativeTextInput is an HtmlElementView, so Flutter's ShaderMask cannot fade its placeholder. Treat the visible placeholder as content while the input is empty and update the input's CSS alpha mask from synthetic rubberband metrics; clear it when the drag settles. Keep Flutter's alpha-mask subtree mounted with an identity mask when no edge is fading. Multiline placeholders are top-aligned, normally wrapped, and participate in the vertical rubberband/fade wrapper.

**Why:** Native placeholder ellipsizing hides the actual product copy and does not participate in the same edge treatment or rubberband motion as normal text. A separately positioned search placeholder can remain visually detached from the field's real gesture even when its offset is manually mirrored. Web platform views bypass Flutter shader masks, so their placeholder fade must be applied by the DOM input itself. Removing the Flutter alpha mask on release reparents animated field content and snaps it; idle zero-offset metrics can also erase a fitting-text fallback while the pointer is still down.

**How to apply:** Use NativeTextInput's placeholder for AppSearchBar so it shares the field's transformed subtree. On web, calculate width from the placeholder while empty and apply CSS alpha fades from the same synthetic drag metrics. Keep separately rendered Flutter placeholders for fields that need that arrangement. For fitting content, keep the fallback's synthetic offset authoritative through the active gesture. Keep the Flutter alpha mask mounted and return an opaque identity shader when fades are off.
