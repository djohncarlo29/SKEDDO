---
name: Menu submenu chevron weight
description: Weight styling for nested menu disclosure chevrons
---

Use medium weight (`FontWeight.w500`) for every chevron that opens a nested menu, including the submenu row indicator and the nested panel header chevron. Keep its weight the same while open or closed.

**Why:** The user requested one weight step thicker than the previous menu chevrons, consistently across their states.

**How to apply:** Preserve existing size scaling, rotation, color, and alignment; increase only the glyph weight.
