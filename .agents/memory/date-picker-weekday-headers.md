---
name: Date-picker weekday headers
description: The app-wide visual convention for weekday rows in calendars and modal date pickers.
---

All calendar and modal date-picker weekday header rows use Monday-first single-letter labels: `M T W T F S S`.

**Why:** The user requested one unified weekday presentation across Year, Month, Day, and date-picker views.

**How to apply:** Keep full weekday names for recurrence logic, prose, and date-banner text when needed, but do not use `Mon`, `Tue`, or similar multi-letter labels in date-picker header rows. Check both the general date picker and the separate Repeat → End Date month-grid header in the New Event sheet.
