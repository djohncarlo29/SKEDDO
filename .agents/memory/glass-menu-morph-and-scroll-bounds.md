## Rule
Toolbar menus should use the same normal morph spring, trigger-to-surface path, opening blur ramp, adaptive premium quality request, and shared content scale/blur profile as `GlassPopover`. Keep the full content group at its settled screen position behind the morphing clip: counter-translate it against the platter's live travel, start 12% oversized with 2px blur at progress 0, then spring to scale 1 and blur 0. Use foreground lens optics of thickness 30, refractive index 1.30, and chromatic aberration 0.40 so clipped text and icons visibly refract at the moving edge. Do not delay-mount, fade in, shrink, or move content with the surface; clip the enlarged group at the live platter bounds in both directions. Only Sort By and directional option rows with checkmark leading slots override their own horizontal inset to zero; parent rows and dividers retain a separate standard 12px inset, even when a menu sets its option-row inset to zero. Modal picker menus keep the standard 12px platter inset for both rows and dividers. For pinned toolbar menus, use the popover's 0.3 stretch amount, 0.08 resistance, and 4px rightward settled landing offset. The premium request remains capped by adaptive device quality. The menu scroll indicator should travel only along the straight-sided portion of its card, ending one corner radius from each outer edge.

**Why:** The user wants toolbar menus to morph like the circle-trigger discard confirmation. Standard quality suppresses the trigger ghost during close, per-row scale/fade changes content motion, immediate menu spring start skips the popover's two-stage layout handoff, and the menu's larger default stretch feels more elastic. Content must be oversized from the first transition frame and revealed only as the glass bounds grow, while staying at its final destination instead of traveling from the trigger. Scaling the list as a group also scales its element positions. The user wants clipped foreground elements to show a clearly visible lens response, so the separate content lens uses stronger optics than the base 20/1.10/0.20 values without changing surface settings. A 16px checkmark edge gap applies only to Sort By option rows, not its parent or divider; separators need a separate inset so they are unaffected by option-row overrides.

**How to apply:** When changing `GlassMenu` morph behavior, compare its spring, path, blur ramp, render quality, layout-start timing, stretch, and content motion with `GlassPopover`; preserve the menu's existing radius and size. Keep the full target list mounted at transition progress 0, counter the moving platter's position with a local content offset, apply the shared group scale and blur, and rely on the current glass clip for reveal. Apply `contentHorizontalInset: 0` to individual Sort By option rows only; use the divider-specific inset for separators, never the row override. Derive the indicator track's top and bottom insets from the active menu radius.
