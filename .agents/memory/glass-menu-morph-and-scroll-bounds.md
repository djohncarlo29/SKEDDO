---
name: GlassMenu morph and scroll bounds
description: Keep toolbar-menu transitions aligned with GlassPopover and keep scroll-indicator travel clear of rounded corners
---

## Rule
Toolbar menus should use the same normal morph spring, trigger-to-surface path, opening blur ramp, adaptive premium quality request, and shared content scale/blur profile as `GlassPopover`. Keep the full content group at its settled layout behind the morphing clip: start 12% oversized with 2px blur at progress 0, then spring to scale 1 and blur 0. Do not delay-mount, fade in, or shrink content along with the surface; clip the enlarged group at the live platter bounds. Only Sort By and directional option rows with checkmark leading slots override their own horizontal inset to zero; the parent Sort By row, separator, and modal picker menus keep the standard 12px platter inset. For pinned toolbar menus, use the popover's 0.3 stretch amount, 0.08 resistance, and 4px rightward settled landing offset. The premium request remains capped by adaptive device quality. The menu scroll indicator should travel only along the straight-sided portion of its card, ending one corner radius from each outer edge.

**Why:** The user wants toolbar menus to morph like the circle-trigger discard confirmation. Standard quality suppresses the trigger ghost during close, per-row scale/fade changes content motion, immediate menu spring start skips the popover's two-stage layout handoff, and the menu's larger default stretch feels more elastic. The user also wants its settled destination 4px right of the prior position. Content must be oversized from the first transition frame and revealed only as the glass bounds grow; scaling the list as a group also scales its element positions. A 16px checkmark edge gap applies only to the Sort By option rows, not its parent or separator.

**How to apply:** When changing `GlassMenu` morph behavior, compare its spring, path, blur ramp, render quality, layout-start timing, stretch, and content motion with `GlassPopover`; preserve the menu's existing radius and size. Keep the full target list mounted at transition progress 0, apply the shared group scale and blur, and rely on the current glass clip for reveal. Apply `contentHorizontalInset: 0` to individual Sort By option rows only; never apply it to the parent submenu row, divider, or all modal picker rows. Derive the indicator track's top and bottom insets from the active menu radius.
