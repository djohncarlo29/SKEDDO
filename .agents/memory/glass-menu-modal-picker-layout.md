---
name: Modal picker menu layout
description: Selection mark sizing and spacing for modal-sheet picker menus
---

Modal-sheet picker `GlassMenu` uses premium quality, matching the captured renderer used by `GlassPopover` and Calendar `GlassBarItem.menu`; the package adaptively falls back when the premium shader is unavailable. The moving tab lens and all three popover/menu surfaces share `thickness: 20`, `refractiveIndex: 1.10`, and `chromaticAberration: 0.20`, so the animated shape refracts the live backdrop consistently during opening and dismissal. These surfaces receive the same piecewise-linear Popover/menu opacity and blur anchors and the shared rim-strength target used by the toolbar/tab bar. Modal picker menus use the toolbar's theme-specific surface tint (white in Light Mode, `#3E3E40` in Dark Mode) while retaining the Popover/menu opacity and blur curves. Dark menus retain the package's baseline key-light intensity; only interaction glow has its separate reduced setting. Resolve brightness from `CupertinoTheme`, not device platform brightness, so the app's explicit appearance setting is respected. Picker menus morph from the measured text-trigger dimensions without rendering a separate trigger glass blob; keep the existing trigger fade timing by ramping menu-surface visibility in the same source interval. Their opening response is a subtle spring and the trigger remains plain text. During dismissal, hold the fully-open menu radius until the bounds cannot contain it, then follow half the short side as a stadium until it disappears. The platter has a 12pt content inset plus each row's 16pt inset, placing the 24pt OS-scaled leading icon slot 28pt from the surface edge. A 17pt OS-scaled checkmark sits centered in that slot, followed by a 12pt icon-label gap and 17pt label text; every row reserves the slot, allows multiline wrapping, and has no trailing icons. Disable the selector/interaction highlight while preserving normal taps. Freeze single-select option visuals through dismissal so the newly selected color does not flash during the reverse morph; multi-select pickers such as Group Include remain open and update live. Normalize the trailing trigger's return overshoot to the available anchored menu height so menu length does not change its spring travel. If the full menu cannot fit beside its trigger, keep the platter anchored to the trigger edge, cap its viewport to the available side, and scroll its options instead of clamping the whole platter away.

**Why:** Picker menus should match Calendar menu typography, spacing, captured-glass rendering, and neutral row behavior while keeping long choices readable and the checkmark accessible at OS text sizes. Their Light/Dark tint should match toolbars even though the menu keeps its separate slider-driven opacity. The shared lens values keep backdrop distortion continuous as the shape grows or shrinks. Standard quality can degrade to a blur-and-tint fallback instead of the full captured renderer. The package calls selection callbacks before starting its reverse morph and its trigger travel otherwise scales with menu height.

**How to apply:** Use a 12pt platter inset, 16pt row inset, 24pt scaled icon slot, 17pt scaled checkmark, 12pt gap, and 17pt title. For picker menus, set premium quality, `showItemInteractionHighlight: false`, `allowTextWrapping: true`, `morphFromZero: false`, `suppressTriggerGlassBlob: true`, and a subtle nonzero `triggerEntryImpactStrength`; pass `skeddoModalSheetPickerGlassSettingsFor(CupertinoTheme.brightnessOf(context), ...)` through `skeddoNavigationGlassSettingsFromShared` to get the toolbar tint and Popover slider curves. Keep the pre-selection action snapshot until `GlassMenuController.isOpen` becomes false only for close-on-tap rows; do not snapshot `closeMenuOnTap: false` multi-select rows. Enable normalized trigger return overshoot for all modal picker menus. For overflow, choose below if it fits, otherwise above if it fits, otherwise use the side with more room and scroll.


## Foreground content edge lens

A glass container's refraction affects the backdrop; its own descendants are intentionally excluded from that inherited lens. To make menu rows, labels, and icons distort as the moving edge passes over them, apply a separate edge-local image-filter lens to the actual foreground content during opening and dismissal, and leave it inactive once settled. Keep the surface's premium quality configuration independent from this foreground pass; unsupported renderers should retain their normal package fallback. Warm the foreground shader before the first interaction.

**Why:** A premium backdrop capture does not by itself refract the menu's own content, which can make the foreground appear optically flat while the glass shape morphs.

**How to apply:** When adding or changing morphing glass menus, inspect both the backdrop material and the foreground child tree. Test transition behavior separately from the settled state, and never lower the package quality to approximate a foreground lens.
